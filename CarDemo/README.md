## Objective

The objective of this laboratory is to understand the basic concepts of Object-Oriented Programming (OOP) by identifying real-world objects, designing UML class diagrams, and implementing those designs using Java classes. This lab demonstrates object creation, constructors, methods, and object interaction.

## CarDemo

The CarDemo project demonstrates the concept of classes and objects using a Car class. It includes object creation, attributes, constructors, methods, and multiple car objects with different states.

### Features

* Car class with attributes
* Constructors
* Multiple objects
* Engine start/stop
* Driving and movement methods
* Object state display

---

## CalculatorDemo

The CalculatorDemo project demonstrates basic mathematical operations using Java methods.

### Features
